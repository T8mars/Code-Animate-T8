# SKILL 实测记录（2026-10-31）

测试方法：让一个全新的 Claude 只读本 SKILL 文件夹（不看片子源码），收到一句话「用演示场景的风格做个 10 秒片头」，按 SKILL 流程从零做完。机器：云端 2 核 CPU，无显卡。

| 阶段 | 用时 |
|---|---|
| 装环境（npm install + playwright 浏览器，含读文档） | 69 秒 |
| 写 scene.js | 86 秒 |
| 截静帧检查（4 轮，修了 3 处） | 69 秒 |
| 渲染 300 帧（约 0.135 秒/帧） | 43 秒 |
| **合计** | **约 4.5 分钟** |

成片：10.000 秒，1920×1080，30fps。内容：等离子背景 + 星空 + 铜条，打字机打出 A CODE-FILM PRODUCTION → 扭曲霓虹格子隧道 + 旋转线框立方体 + 正弦滚动问候语 → 8.4 秒白闪冲击波，故障切片砸出「NEON//2026」→ 停在 EVERY FRAME IS WRITTEN。源码见 `demoscene_intro_scene.js`。

测试中发现的说明问题（已全部改进 SKILL.md 和模板）：画法库引用的源码路径、必须提供 initFilm/renderFrame、makeGL 的用法、字体字重和显式加载、.done 文件、200% 检查的做法、渲染参数已内置、Playwright 版本锁定。
